# اتصال به API مالی هوم‌گلد

پیاده‌سازی براساس سند `api commodity-v4.pdf` است: احراز هویت با
`POST /ExternalPartnerAuth/token` و دریافت قیمت‌ها با
`GET /PartnerAPI/Ordering/ExternalPartner/commodity`.

## شروع سریع

در `.env` بک‌اند این دو مقدار را تنظیم کنید؛ اطلاعات واقعی اتصال نباید در گیت ثبت شوند:

```dotenv
HOMEGOLD_CLIENT_ID=your-client-id
HOMEGOLD_CLIENT_SECRET=your-client-secret
```

از پوشهٔ `shahrazgold-app` اجرا کنید:

```bash
php artisan config:clear
php artisan homegold:commodities
```

خروجی جدولی شامل شناسه، نام، `buyPrice` و `sellPrice` است. برای JSON:

```bash
php artisan homegold:commodities --json
```

برای احراز هویت مجدد از گزینهٔ `--fresh-token` استفاده کنید. دستور هنگام خطا کد خروج ۱ دارد.

## استفاده در کد Laravel

```php
use App\Services\HomeGoldService;

$products = app(HomeGoldService::class)->commodities();

foreach ($products as $product) {
    $id = $product['CommodityId'];
    $name = $product['name'];
    $buyPrice = $product['buyPrice'];
    $sellPrice = $product['sellPrice'];
}
```

در کنترلر، job یا سرویس نیز می‌توانید `HomeGoldService` را در سازنده یا متد تزریق کنید.
خطاهای اتصال، احراز هویت و پاسخ نامعتبر با `App\Exceptions\HomeGoldException` گزارش می‌شوند؛
متن پاسخ احراز هویت و توکن در پیام خطا چاپ نمی‌شود.

## رفتار اتصال

- توکن در سمت سرور کش می‌شود؛ قیمت‌ها هر بار مستقیماً دریافت می‌شوند.
- مدت کش توکن پیش‌فرض ۳۰۰ ثانیه است. پس از پاسخ ۴۰۱، توکن حذف و درخواست فقط یک بار تکرار می‌شود.
- سند endpoint برای refresh ندارد؛ مقدار `refreshToken` استفاده نمی‌شود.
- ارسال توکن با هدر `Authorization: Bearer` انجام می‌شود و با اتصال واقعی تأیید شده است؛ نوع هدر در PDF تصریح نشده است.
- سرویس واقعی محصولات را در `data` و شناسه را با نام `commodityId` برمی‌گرداند. خروجی این سرویس مطابق نام‌گذاری سند به `CommodityId` تبدیل می‌شود؛ هر دو شکل پاسخ پشتیبانی می‌شوند.
- کش پیش‌فرض `file` است و برای این سرویس به Redis یا دیتابیس نیاز نیست.
- دستور `homegold:commodities` فقط قیمت‌ها را می‌خواند. همگام‌سازی از پنل یا دستور `homegold:sync` فقط قیمت محصولات با اتصال خودکار را به‌روز می‌کند.
- واحد پول و معنای خرید/فروش از دید طرف معامله در سند مشخص نشده؛ قیمت‌ها بدون تبدیل بازگردانده می‌شوند.

تنظیمات اختیاری:

```dotenv
HOMEGOLD_BASE_URL=https://homegold750.ir
HOMEGOLD_TIMEOUT=15
HOMEGOLD_TOKEN_TTL=300
HOMEGOLD_CACHE_STORE=file
```

برای تست بدون اتصال واقعی:

```bash
php artisan test --filter=HomeGoldServiceTest
```

## تست در پنل مدیریت

از منوی مدیریت، «اتصال هوم‌گلد» (`/admin/homegold`) را باز کنید:

1. «دریافت قیمت‌های تازه» را بزنید.
2. محصول شهرازگلد و محصول متناظر هوم‌گلد را انتخاب کنید.
3. واحد پول قیمت دریافتی را مشخص کنید.
4. روش استفاده را «خودکار» یا «دستی» انتخاب کنید. «محاسبهٔ پیش‌نمایش» فقط نتیجه را نشان می‌دهد و قیمت سایت را تغییر نمی‌دهد.
5. تنظیمات را ذخیره کنید. در حالت خودکار، دریافت و اعمال قیمت هر ۱۰ ثانیه انجام می‌شود؛ برای اجرای فوری «دریافت و اعمال الآن» را بزنید.
6. برای برگشت به کنترل دستی، حالت «دستی» را ذخیره کنید؛ سپس از مدیریت قیمت‌ها، قیمت جدید وارد کنید. آخرین قیمت تا زمان ثبت قیمت دستی حفظ می‌شود.

قیمت‌های منبع در کارت‌های بالای صفحه نمایش داده می‌شوند و کارت محصول انتخاب‌شده اول قرار می‌گیرد. اعداد کارت‌ها عین پاسخ منبع هستند؛ قیمت پیش‌نمایش و قیمت ثبت‌شدهٔ سایت به ریال تبدیل می‌شوند.
پنل هر ۱۰ ثانیه وضعیت را می‌خواند؛ اگر فهرست دریافت نشده یا بیش از ۱۵ ثانیه قدمت داشته باشد، درخواست دریافت تازه می‌فرستد. این دریافت، محصول در حالت دستی را بازنویسی نمی‌کند.
نشان «دریافت تازه» برای فهرستی با سن کمتر از ۳۰ ثانیه است و با اعتبار ۱۸۰ ثانیه‌ای اتصال هر محصول برای معامله تفاوت دارد.

فرمول هر سمت:

```text
قیمت نهایی = round(قیمت API × تبدیل پول)
```

قیمت‌های صفحه، پایهٔ مشترک مشتریان هستند؛ تعدیل نقش، تبدیل داخلی محصول ۳ و تعدیل مبلغ نهایی محصول ۱ در جریان سفارش طبق منطق قبلی انجام می‌شوند.
برای محصول ۳ تبدیل داخلی مبلغ بر ۴٫۳۳۱۸۳ همچنان فعال است؛ برای تبدیل واحد قیمت، آن را دوباره اعمال نکنید.
اتصال API محصول ۳ حرکت پله‌ای محصول ۱ را اجرا نمی‌کند. تغییر دستی محصول ۳ نیز محصول ۱ با اتصال خودکار را تغییر نمی‌دهد.

قیمت خرید مشتری از `buyPrice` و قیمت فروش مشتری از `sellPrice` دریافت می‌شود. تقسیم واحد و تعدیل درصدی یا ثابت اعمال نمی‌شود؛ تنظیمات قدیمی این فیلدها نیز نادیده گرفته می‌شوند.
محصول با قیمت فرمولی برای پیش‌نمایش قابل انتخاب است؛ برای اتصال خودکار باید به حالت دستی تغییر کند.
در حالت خودکار، تغییر دستی قیمت مسدود است.
تغییر قیمت خرید یا فروش یک سابقهٔ جدید و یک نسخهٔ قیمت ایجاد می‌کند؛ دریافت قیمت یکسان فقط زمان اعتبار را تازه می‌کند.
آخرین زمان دریافت، آخرین خطا و دادهٔ مبنا روی اتصال ذخیره می‌شود. خطای محصولی باعث توقف همگام‌سازی بقیهٔ محصولات نمی‌شود.
اعتبار قیمت در سرور ثابت و برابر ۱۸۰ ثانیه است. اگر قیمت خودکار هنوز دریافت نشده یا اعتبار آن تمام شده باشد، نمایش قیمت کهنه باقی می‌ماند ولی پیش‌نمایش سفارش و ثبت سفارش متوقف می‌شوند.

## زمان‌بندی

در Docker سرویس `scheduler`، `php artisan schedule:work` را اجرا می‌کند:

```bash
docker compose up -d scheduler
```

در محیط بدون Docker، هنگام توسعه:

```bash
php artisan schedule:work
```

در cPanel یک cron در هر دقیقه تعریف کنید (مسیر PHP و پروژه را مطابق هاست تغییر دهید):

```cron
* * * * * /usr/local/bin/php /home/ACCOUNT/shahrazgold-app/artisan schedule:run >> /dev/null 2>&1
```

زمان‌بندی هر ۱۰ ثانیه قیمت اتصال‌های خودکار را دریافت می‌کند. فاصلهٔ دریافت ثابت است و به تنظیمات قبلی اتصال بستگی ندارد. پنل مدیریت نیز هر ۱۰ ثانیه وضعیت دریافت و قیمت‌های نمایش‌داده‌شده را تازه می‌کند.
در cPanel، cron همچنان هر دقیقه اجرا می‌شود؛ Laravel برای اجرای کارهای زیر یک دقیقه تا پایان همان دقیقه فعال می‌ماند.
در زمان محدودیت درخواست هوم‌گلد یا کندی پاسخ، دریافت موفق ممکن است با تأخیر انجام شود.
بدون اتصال خودکار، اجرای زمان‌بندی هیچ درخواست خارجی نمی‌فرستد.
هر اجرا قیمت همهٔ محصولات را با یک درخواست دریافت می‌کند. برای اجرای دستی:

```bash
php artisan homegold:sync
php artisan homegold:sync --due
```

تست‌های یکپارچه (روی دیتابیس آزمایشی):

```bash
docker compose exec -T app php artisan test --filter=HomeGold
```
