# فونت مستندات

نسخهٔ فارسی مستند جامع از فونت **Vazir (وزیر)**، ساختهٔ صابر راستی‌کردار، استفاده می‌کند.

منبع رسمی و نسخهٔ استفاده‌شده: https://github.com/rastikerdar/vazirmatn/tree/v30.1.0

فایل‌های `Vazir-Regular.woff2` و `Vazir-Bold.woff2` برای ساخت سند استفاده می‌شوند و در HTML نهایی به‌صورت داخلی قرار می‌گیرند؛ نمایش سند به اینترنت وابسته نیست. متن مجوز در `LICENSE-Vazir.txt` است.
