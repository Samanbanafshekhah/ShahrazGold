گزارش تغییرات پروژه ShahrazGold
تاریخ: 2026-08-17
مسیر پروژه: /var/www/ShahrazGold

============================================================
1) خلاصه کارهای انجام‌شده
============================================================

- نصب و راه‌اندازی Laravel با PHP 8.3 و Composer.
- تنظیم محیط محلی روی SQLite و اجرای migrationها.
- انتقال خروجی آماده public_html به public لاراول برای اجرای هم‌زمان فرانت و API.
- اضافه‌شدن public/index.php استاندارد Laravel.
- حذف دکمه و لینک ثبت‌نام از صفحه /login و لندینگ، در دسکتاپ و موبایل.
- حذف متن اطلاعات ورود آزمایشی.
- تغییر فرم ورود ادمین از ایمیل به شماره موبایل و اتصال آن به ورود واقعی Laravel.
- حذف پیام «نسخه دمو — تمام عملیات به‌صورت شبیه‌سازی و بدون سرور انجام می‌شود.» از پنل ادمین.
- حذف محدودیت 5 دقیقه‌ای و خطای «قیمت این محصول قدیمی است...» از ثبت درخواست.
- تغییر متن وضعیت از «قیمت‌ها آنلاین است» به وضعیت مدیر.
- اضافه‌شدن کلید روشن/خاموش وضعیت مدیر در داشبورد ادمین.
- ذخیره وضعیت مدیر در دیتابیس و محافظت مسیر تغییر با دسترسی admin.
- نمایش «مدیر آنلاین است» با رنگ سبز و «مدیر آفلاین است» با رنگ قرمز در داشبورد مشتری.
- دریافت وضعیت مدیر توسط داشبورد مشتری هر 3 ثانیه.
- ایجاد یک کاربر admin و یک کاربر customer فعال در SQLite. رمزها عمداً در این گزارش درج نشده‌اند.

نکته مهم فرانت:
سورس اصلی frontend داخل نسخه فعلی پروژه موجود نیست. فایل‌های فرانت موجود، خروجی build و minify شده‌اند.
به همین دلیل اصلاحات رابط کاربری مستقیماً روی bundleهای فعال انجام شده‌اند.

5) دستورهای مهم اجرا و راه‌اندازی
============================================================

نصب dependencyهای PHP:

composer install

پاک‌سازی cache لاراول:

php artisan optimize:clear

اجرای محلی Laravel:

php artisan serve --host=127.0.0.1 --port=8090
php artisan serve --host=127.0.0.1 --port=8091
php artisan serve --host=127.0.0.1 --port=8092

انتقال خروجی public_html به public لاراول:

mkdir -p public/assets public/storage
rsync -a ../public_html/assets/ public/assets/
rsync -a ../public_html/storage/ public/storage/
rsync -a ../public_html/index.html ../public_html/favicon.ico ../public_html/manifest.webmanifest ../public_html/robots.txt ../public_html/ShahrazGoldLogo2.png public/

اجرای patch رابط وضعیت مدیر:

node scripts/patch-manager-status-ui.mjs

============================================================
6) API جدید وضعیت مدیر
============================================================

خواندن وضعیت برای فرانت مشتری:

GET /api/v1/manager-status

نمونه پاسخ خاموش:

{"success":true,"message":"OK","data":{"online":false},"meta":{}}

تغییر وضعیت توسط مدیر احراز هویت‌شده:

PUT /api/v1/admin/manager-status
Content-Type: application/json
Authorization: Bearer ADMIN_TOKEN

بدنه روشن:

{"online":true}

بدنه خاموش:

{"online":false}

این مسیر بدون توکن admin پاسخ 401 می‌دهد.

============================================================
8) نکات استقرار
============================================================

1. قبل از انتقال، از دیتابیس سرور backup تهیه شود.
2. فایل‌های Laravel بخش 2 و فایل‌های frontend بخش 3 منتقل شوند.
3. دستور php artisan migrate --force اجرا شود.
4. دستور php artisan optimize:clear اجرا شود.
5. دسترسی نوشتن storage و bootstrap/cache بررسی شود.
6. پس از انتشار، مرورگر با Ctrl+Shift+R تازه‌سازی شود؛ چون نام hash فایل‌های bundle تغییر نکرده است.
7. اگر سورس اصلی frontend بعداً پیدا شد، همین تغییرات باید داخل source componentها پیاده‌سازی و build جدید تولید شود؛ ویرایش bundle راهکار موقت برای نسخه فعلی است.
